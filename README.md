# PlanningSync 📅

**PlanningSync** is a modern, full-stack Event Planner and Daily Habit Tracker designed to help users organize their lives, stay productive, and maintain healthy habits.

---

## Features

### Event Management
- **Interactive Calendar**: Visualize your schedule with a monthly calendar view.
- **Event Controls**: Create, update, and delete events with ease.

### Habit Tracking
- **Habit Goals**: Define habits with specific recurrence (Daily, Weekly, Monthly).
- **Streak System**: Stay motivated with habit completion streaks.
- **Visual Timelines**: Track your progress over time with a visual habit timeline.

### User Experience
- **Profile Management**: Update user information, including contact details and location.
- **Secure Auth**: Robust authentication system using Spring Security and JWT.
- **Location Awareness**: Associate users with their respective provinces, districts, and villages.

### Admin
- **User Management**: Comprehensive dashboard for admins to manage users.
- **Location Management**: Comprehensive dashboard for admins to manage locations. 
- **System Metrics**: Real-time stats on total users and locations.
